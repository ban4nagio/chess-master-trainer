# Chess Master Trainer

Desktop chess trainer app built in Python with Tkinter and python-chess.

## Features

- 3 levels: Beginner, Intermediate, Advanced
- 2 daily lessons with YouTube videos
- Chess coach explanations for openings, tactics, and strategic principles
- Human-vs-trainer gameplay with guided feedback
- Practical teaching approach inspired by a chess master coach

## Run

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## Level structure

- Beginner: openings, center control, simple tactics
- Intermediate: Sicilian ideas, double checks, tactical patterns
- Advanced: strategic plans, intermezzo, endings and conversion

## Project note

This project is a training game meant to teach chess logic, not just move pieces randomly. Each move is paired with coach guidance and lesson content.
